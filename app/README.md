# CleanScape app

Expo (React Native) app for CleanScape (Project Falcon, UAE).

- Plan & decisions: [Miro board](https://miro.com/app/board/uXjVEUrD-Lo=/)
- Design: [Figma – CleanScape Rain Ready (UAE)](https://www.figma.com/design/6Jc3DgUuXJDOdc5Z4IC4Lm/)
- Rules for humans and AI: [PROJECT_RULES.md](PROJECT_RULES.md)
- Current state, checks and open items: [PROJECT_STATUS.md](PROJECT_STATUS.md)

## Run
```
npm install
npx expo start   # scan the QR code with Expo Go on your iPhone
```
